# Changelog

## 0.3.1.0

- Added Stream Deck + dial support through Encoder controllers.
- Bumped Marketplace compatibility to Stream Deck 6.9+ and manifest SDK 3.
- Added official Elgato CLI packaging.
- Added PNG and @2x manifest icons for clean validation.
- Preserved local LG webOS control for volume, mute, media, apps, inputs, and status.

## 0.2.4.0

- Replaced unreliable foreground-state play/pause logic with a local optimistic toggle.
- Kept explicit play and pause actions available for direct control.

## 0.2.3.0

- Refined Stream Deck key icons with LG red styling and Lucide glyphs.
- Improved volume up and volume down icon alignment.
